# VR Dream Space 🌴✨

**My first VR project**, created as part of a future-themed assignment about where we see ourselves in the years to come.  
This immersive WebXR experience is inspired by a real dream of mine — living in the Dominican Republic.

## Live Site

[Explore the space on Netlify](https://vrspacealex.netlify.app/)

## Built With

- A-Frame for 3D/VR scene construction
- **Blender** for 3D modeling and textures
- Basic HTML structure + GLTF assets
- Custom audio logic and animations
- Netlify for hosting

## Features

- Eco-style cabin and beach-jungle layout
- Animated flying phoenix and orbiting butterfly
- Interactive 3D models that play sounds when approached or clicked
- Headset-compatible (WebXR support)
- A glowing blue portal that connects my scene with my teammates' spaces. This feature works only within our shared repository: [futurespaces](https://github.com/fthuggy/futurespaces)
